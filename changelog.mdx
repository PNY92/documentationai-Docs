## Recent Updates

Stay updated with the latest improvements to Wally And Cody. Check your current version in the dashboard settings and upgrade via the CLI for the newest features.

<Callout kind="info" collapsed="false">
  To check your version, run `wally version` in your terminal. Upgrades include auto-redeem enhancements and better Shopee integration.
</Callout>

<Update label="2024-10-15" description="v1.2.0" tags={["feature","improvement"]}>
  ## New Features

  - Instant redeem links now support bulk order IDs for faster processing.
  - Added dashboard analytics to track successful redemptions over time.

  ## Improvements

  - Reduced processing time by `>30%` for high-volume orders.
  - Enhanced error handling for invalid Shopee order formats.

  ## Bug Fixes

  - Fixed occasional failures on orders with special characters in IDs.
  - Resolved mobile responsiveness issues in the redeem interface.
</Update>

<Update label="2024-09-20" description="v1.1.0" tags={["bugfix","security"]}>
  ## Bug Fixes

  - Patched vulnerability in order ID validation to prevent injection attempts.
  - Corrected sync issues between auto-redeem system and Shopee API.

  ## Improvements

  - Optimized pop-up interface for quicker `Get redeem link` actions.
</Update>

<Update label="2024-08-10" description="v1.0.0" tags={["feature","breaking"]}>
  ## New Features

  - Core auto-redeem system: Enter Shopee order ID and get links instantly.
  - Instant delivery notifications for all successful redemptions.

  ## Breaking Changes

  - Updated API endpoints from `/v0/redeem` to `/v1/redeem`. Update your integrations.
</Update>

## Upgrade Process

Follow these steps to upgrade to the latest version.

<Steps>
  <Step title="Check Current Version" icon="info" title-type="p">
    Run the version check command.

    ```bash
    wally version
    ```
  </Step>

  <Step title="Update CLI" icon="download" title-type="p">
    Install the latest release.

    <CodeGroup show-lines="true">
      ```bash
      npm install -g wally-and-cody@latest
      ```

      ```bash
      yarn global add wally-and-cody@latest
      ```
    </CodeGroup>
  </Step>

  <Step title="Verify Update" icon="check-circle" title-type="p">
    Confirm the new version.

    ```bash
    wally version
    ```

    Expect output like `v1.2.0`.
  </Step>
</Steps>
