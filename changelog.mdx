## Release history

The Shopee Auto Redeemer platform has evolved through several major milestones. Each release expanded the system from a basic order-to-link lookup into a full-stack automation platform with Google Drive matching and MCP integration.

<Update label="2024-12-01" description="v2.4.0" tags={["feature"]}>
  ## New Features

  - Added MCP Server with stdio and authenticated HTTP transport.
  - Exposed 9 MCP tools: `list_products`, `get_product`, `list_redemption_targets`, `set_product_redemption_link`, `set_variant_redemption_links`, `assign_missing_redemption_links`, `sync_products`, `get_sync_status`, and `get_token_health`.
  - Added host allowlisting and origin allowlisting for MCP HTTP transport.

  ## Improvements

  - Scoped the MCP server to one seller or shop for safety. Seller administration, boosting, and stock changes are not exposed.
</Update>

<Update label="2024-10-15" description="v2.3.0" tags={["feature"]}>
  ## New Features

  - Added Inventory Agent with Google Drive integration.
  - Implemented matching priority for approved matches, exact SKU, exact name, and optional OpenRouter semantic matching.
  - Added SQLite state persistence for the Inventory Agent.
  - Added a batch redemption target assignment endpoint with fingerprint safety checks.

  ## Improvements

  - Inventory Agent preserves existing URLs and only fills missing ones.
  - Uncertain matches remain available for manual review.
</Update>

<Update label="2024-08-20" description="v2.2.0" tags={["feature"]}>
  ## New Features

  - Added product boosting with round-robin campaign support.
  - Added a boost-selection toggle endpoint for enabling or disabling products.
  - Added a round-robin boost run endpoint.

  ## Improvements

  - Product boost state is tracked per product in the `products` table.
  - Added a dedicated product boosting table to the admin dashboard.
</Update>

<Update label="2024-06-10" description="v2.1.0" tags={["feature","improvement"]}>
  ## New Features

  - Added support for multiple labeled, ordered redemption URLs per model.
  - Added a public redemption directory at `/r/:directory_key` for multi-URL models.
  - Added the directory resolution endpoint `GET /api/redemption/directories/:directory_key`.

  ## Improvements

  - Added the `product_model_redemption_urls` table through a database migration.
  - Extended redemption URL length support through a database migration.
  - Added the following URL resolution priority chain: multi-URL directory, single model URL, product URL, then `CONTACT_SELLER_REQUIRED`.
</Update>

<Update label="2024-04-01" description="v2.0.0" tags={["feature","breaking"]}>
  ## New Features

  - Rewrote the platform with Bun, Express 5, and TypeScript.
  - Added a PostgreSQL 17 database with `sellers`, `shops`, `products`, and `product_models` tables.
  - Added Redis 7 and BullMQ for background job processing.
  - Added JWT authentication with `ADMIN` and `SELLER` roles.
  - Added the Shopee OAuth flow with an automatic token refresh worker.
  - Added product synchronization with incremental and full modes.
  - Added a public redemption portal for buyer order lookup.
  - Added an admin dashboard built with React 19, Vite, Tailwind CSS, and Radix UI.
  - Added Docker Compose orchestration for all services.

  ## Breaking Changes

  - Replaced v1 API endpoints and updated all paths to use the `/api/` prefix.
  - Rebuilt the database schema. v1 data is not compatible with v2.
</Update>

<Update label="2024-01-15" description="v1.0.0" tags={["feature"]}>
  ## New Features

  - Added the initial auto-redeem system, which accepts a Shopee order ID and returns redemption links.
  - Added basic Shopee integration for order lookup.
  - Added product-level redemption URL configuration.
</Update>
