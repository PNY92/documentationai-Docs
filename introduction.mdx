## Wally And Cody

<Image src="https://blob-cdn.documentation.ai/org-2ebb2ef5-dd91-493f-9938-283fbdb14c81/doc-d2a73d2e-4391-4446-a5c8-2d0b41b7c4c1/1774416239742-jgnpt0hlw7r-starter_img_1.starter_img_1?q=85&fm=auto&auto=compress%2Cformat" width="800" height="400" alt="Wally And Cody documentation" />

Wally And Cody is a full-stack platform that automates Shopee product redemption. Sellers connect their shops, sync products, and attach digital redemption URLs. Buyers enter a Shopee order ID on the public portal and instantly receive their redemption links.

## Key Components

<Columns cols="2">
  <Card title="Backend API" icon="server" horizontal="false">
    Bun, Express, PostgreSQL, and Redis power shop connections, product synchronization, and redemption workflows.
  </Card>

  <Card title="Admin Dashboard" icon="monitor" horizontal="false">
    React 19 tools for managing products, redemptions, shops, and seller operations.
  </Card>

  <Card title="Public Redemption Portal" icon="shopping-bag" horizontal="false">
    A buyer-facing order lookup experience that returns the redemption links associated with a Shopee order.
  </Card>

  <Card title="Inventory Agent" icon="bot" horizontal="false">
    Automatically matches inventory from Google Drive with products that need redemption URLs.
  </Card>

  <Card title="MCP Server" icon="code" horizontal="false">
    Programmatic access for connecting compatible tools and automating platform workflows.
  </Card>

  <Card title="Background Worker" icon="refresh-cw" horizontal="false">
    Handles token refresh and product synchronization tasks outside the main request flow.
  </Card>
</Columns>
