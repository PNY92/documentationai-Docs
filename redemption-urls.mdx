## Redemption URLs

Redemption URLs tell the platform where to send buyers after they purchase. You can set one link for an entire product, or different links for each variant.

<Callout kind="tip">

Plan your URLs before configuring them. If you sell software with Windows, Mac, and Linux versions, set up labeled URLs for each at the model level.

</Callout>

<Steps>
<Step title="Understand product-level vs model-level URLs" icon="info">

A **product-level URL** applies to all variants of a product. Every buyer who buys any version gets the same link.

A **model-level URL** applies to a specific variant, such as a size or color. If you set both, the model-level URL takes priority for that variant. If no model-level URL exists, the product-level URL is used instead.

> 📸 **Screenshot:** Diagram showing product-level URL vs model-level URLs for different variants

</Step>

<Step title="Set a single product-level URL" icon="link">

Go to the **Products** page in your dashboard. Find the product you want to configure and click **Edit URLs**. Enter the URL in the product-level field, then click **Save**.

This link will be shown to buyers for all variants of this product unless you set a model-level URL.

> 📸 **Screenshot:** Product edit panel with the product-level URL field highlighted

</Step>

<Step title="Set a model-level URL for a specific variant" icon="list">

In the product's URL editor, find the variant, or model, you want to configure. Enter the URL in that model's field and click **Save**.

This link overrides the product-level URL for this specific variant only.

> 📸 **Screenshot:** Model-level URL field for a specific variant within the product editor

</Step>

<Step title="Configure multiple labeled URLs for a model" icon="layers">

For a single variant, you can add multiple URLs with labels, such as separate download links for Windows, Mac, and Linux.

In the model's URL editor, click **Add URL**. Enter a label, such as **Windows Download**, paste the URL, set the display order, and toggle the link active or inactive. Repeat for each link you want to add. Only active links are shown to buyers.

> 📸 **Screenshot:** Multiple labeled URLs listed for a single model variant with sort order and active toggles

</Step>

<Step title="Use batch assignment for many products" icon="copy">

If you have many products that need URLs, use the batch assignment tool. On the **Products** page, select multiple products, then click **Batch Assign URLs**.

Choose whether to set product-level or model-level URLs, enter the URL for each, and click **Apply**. The tool preserves existing links and only updates the ones you specify.

> 📸 **Screenshot:** Batch assign URL dialog with multiple products selected and URL input fields

</Step>

<Step title="Optionally enable the Inventory Agent" icon="sparkles">

The Inventory Agent can automatically match products to URLs based on files in your Google Drive. This option is useful if you have many similar products.

Enable it from the **Inventory Agent** settings page in the dashboard. The agent suggests matches and leaves uncertain ones for you to review manually.

> 📸 **Screenshot:** Inventory Agent settings page with enable toggle and match suggestions

</Step>
</Steps>

Once your URLs are set, buyers will see them when they enter their order ID on the redemption portal. Make sure all your products and variants have URLs assigned to avoid the `CONTACT_SELLER` warning.

<Callout kind="info">

If a buyer sees a `CONTACT_SELLER` message, it means no URL was found for the product or variant they purchased. Go back to the **Products** page and assign a URL to that item.

</Callout>
