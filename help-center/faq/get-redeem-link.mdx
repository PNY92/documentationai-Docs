## Overview

You can quickly get your redeem link using your Shopee order ID on Wally And Cody.

## Steps

1. Go to [https://wallyandcody.com/redeem](https://wallyandcody.com/redeem)
2. Enter your Shopee order ID
3. Tap "Generate Redeem Link"
4. Copy your link and use it to access documentation

## Note

Redeem links are unique to each order ID and expire in 24 hours.
